# F-003 Debug Console & Overlay — Manual Test

Run the project from the 4.7.2 editor (F5, a debug build).

1. **Overlay:** top-right shows `FPS`, `State: MENU`, `Actors: 0`, `Chunks: —`, `Day: —`, updating ~4×/s.
2. Press `` ` ``: the console drops down from the top with the input focused. No backtick appears in the input.
3. Type `help` → Enter: lists `clear, help, overlay, state, timescale`.
4. `help timescale` → shows `timescale <x>` and its description.
5. `timescale 0.5` → "Time scale: 0.5". `timescale` → prints the current value.
6. `state town` → overlay shows `State: TOWN`. `state bogus` → lists valid states.
7. `foo` → red "Unknown command 'foo'. Type 'help'."
8. `say "hello world` (unterminated quote) → red "Unterminated quote."
9. Press ↑ repeatedly → walks back through previous commands; ↓ walks forward and finally clears.
10. `overlay off` hides the overlay; `overlay on` shows it.
11. `clear` empties the output.
12. Press `` ` `` again: the console closes.
