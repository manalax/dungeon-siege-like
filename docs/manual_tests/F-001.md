# F-001 Input Map & Settings — Manual Test

1. Open the project in Godot 4.7.2 → **Project → Project Settings → Input Map**.
2. Tick **Show Built-in Actions** off. Confirm 45 custom actions are listed, e.g. `move_click` (LMB), `select_all` (Ctrl/Cmd+A, Home), `tactical_pause` (Space), `ability_1`–`ability_6` (1–6), `camera_pan_forward` (W, physical), `build_mode` (B), `haggle_up` (Up, Wheel Up), `debug_console_toggle` (`` ` ``).
3. Confirm each binding shows **All Devices**.
4. To change a default binding: edit `core/input/input_actions.gd`, then run
   `$GODOT --headless --path . -s res://tools/generate_input_map.gd` and re-run the tests.
   (Editing bindings in the editor UI works too, but `test_project_bindings_match_table` will fail until the table matches.)
