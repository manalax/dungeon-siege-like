# F-002 Autoload Scaffolding — Manual Test

1. Open the project in Godot 4.7.2 → **Project → Project Settings → Globals → Autoload**.
2. Confirm 15 entries, all with **Global Variable** enabled, in this order:
   EventBus, InputMapSetup, Game, Calendar, Economy, Roster, Party, RunManager,
   WorldStreamer, ItemFactory, LootService, ShopManager, Market, SaveManager, AudioManager.
3. Press **F5**. The scene runs with no errors or warnings in the Output panel
   (an `InputMapSetup registered actions missing…` warning means project.godot drifted from `InputActions.ACTIONS`).
4. While running, open **Remote** in the Scene dock and confirm the 15 nodes sit under `/root`.
