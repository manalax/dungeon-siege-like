1. Open `/Applications/Godot_4.7.2_mono.app`, then **Import** and pick this folder's `project.godot`.
2. Confirm the editor opens with **no errors** in the Output panel.
3. **Project → Project Settings → Layer Names → 3D Physics**: layers 1–9 read
   `world, party, monsters, npcs, projectiles, pickups, triggers, click_pick, build_grid`.
4. **Project → Project Settings → Plugins**: *Gut* is enabled. A **GUT** tab appears in the bottom panel.
5. In the GUT panel, click **Run All**. Expect 3/3 tests passing.
6. Press **F5**. Expect a window showing a procedural sky with a light and no geometry, and no errors.
7. Confirm the FileSystem dock does **not** list `POLYGON_BossZombies_SourceFiles_v4` (it is `.gdignore`d).
